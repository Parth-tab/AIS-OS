# C++ Programming Language

C++ is a high-performance, compiled, general-purpose programming language created by Bjarne Stroustrup as an extension of the C programming language. It is widely used in systems programming, game development, and applications requiring fine-grained control over resources and memory.

## Core Features
- **Object-Oriented Programming**: Support for classes, objects, [encapsulation](file:///E:/AIOS/AIS-OS/wiki/wiki/concepts/encapsulation.md), inheritance, and polymorphism.
- **Low-Level Memory Access**: Allows direct control over memory via pointer manipulation and manual [memory allocation (Stack vs Heap)](file:///E:/AIOS/AIS-OS/wiki/wiki/concepts/stack_vs_heap.md).
- **Strongly Typed**: Offers type safety and compiled efficiency.
