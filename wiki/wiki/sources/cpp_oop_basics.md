# Source: C++ OOP & Memory Basics

A reference summary of the core concepts described in the raw source [cpp_oop_basics.txt](file:///E:/AIOS/AIS-OS/wiki/raw/cpp_oop_basics.txt).

## Core Takeaways
- **C++ Class & Objects**: A class is a blueprint; an object is an instance.
- **Memory Allocation**:
  - **Stack Allocation**: Automatic lifecycle, faster, deallocated when out of scope.
  - **Heap Allocation**: Manual lifecycle via `new` / `delete`, slower, prone to memory leaks if not managed.
- **Encapsulation**: Bundling of data and methods. Access control using `public`, `private` (default), and `protected` specifiers.
