# CS50 Course Context

This is the index for CS50: Introduction to Computer Science.

## Core Structure
- **Language Focus**: C, Python, SQL, HTML/CSS, JavaScript.
- **Key Lectures**:
  1. Week 0: Scratch
  2. Week 1: C
  3. Week 2: Arrays
  4. Week 3: Algorithms
  5. Week 4: Memory (Pointers, malloc, free)
  6. Week 5: Data Structures (Singly linked lists, hash tables, trees)

## Notes Style
We generate notes following the 8-point structure. Examples must be in pure C (for weeks 1-5) or appropriate language. Code must be heavily commented showing low-level memory layout.
